# legged_mjlab

面向 MuJoCo/mjlab 的腿式机器人强化学习框架设计。目标是保留 `legged_gym` 的“配置优先、
最小父类、一个目录一个训练任务、task id”体验，同时使用 mjlab 的 Entity、Scene、manager、
MuJoCo Warp 和独立 RSL-RL 算法包。
