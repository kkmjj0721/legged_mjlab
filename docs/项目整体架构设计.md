# legged_mjlab 项目整体架构设计与实现说明

legged_mjlab 是一个面向足式机器人强化学习的 MuJoCo/mjlab 工程框架。它保留 mjlab 基于 MuJoCo Warp 的并行仿真能力，同时提供接近 legged_gym 的开发体验：配置使用 Python 嵌套类继承，任务通过一个轻量的 task_registry 注册，环境通过 wrapper 适配到独立的 rsl_rl 算法后端。

本文是项目的架构总览、接口合同和实现说明，可以直接作为项目 README 或设计文档使用。
可直接复制的完整文件实现统一放在 `docs/逐文件可复制代码.md`；本文中的代码只用于解释
调用关系和接口合同，不要求读者跨章节拼接代码。凡是标注“目标实现”“待实现”或“未验证”的
内容，都不能理解为当前仓库已经运行通过。

## 1. 设计目标与边界

### 1.1 目标

Manager-based RL 环境适合把观测、奖励、事件和传感器拆成可组合模块，但在腿式机器人训练中，以下数据经常需要跨模块共享：

- 基座姿态、重力投影、线速度和角速度；
- 关节位置、关节速度、默认关节角和动作历史；
- 观测历史、特权观测、HIM latent 和终止帧状态；
- 执行器延迟、动作裁剪、域随机化以及 timeout bootstrap。

因此，legged_mjlab 采用下面的分层原则：

1. mjlab 负责 MuJoCo 场景、实体、传感器、执行器和物理步进。
2. legged_mjlab 负责任务配置、任务语义、观测/奖励/终止约定和任务注册。
3. wrapper 负责把 mjlab 的 observation dictionary 适配成 RSL-RL 需要的张量协议。
4. rsl_rl 负责 PPO、HIM、AMP 等算法的网络、storage、loss 和 runner。
5. 训练脚本只负责解析 CLI、取任务、构造环境和 runner，不直接实现物理逻辑。

### 1.2 非目标

基础层不承担以下职责：

- 不在 him wrapper 中实现 AMP；
- 不在基础环境中直接实现 HIM estimator、HIM loss 或 discriminator；
- 不复制一套 MuJoCo physics loop 取代 mjlab；
- 不把 terminated 和 truncated 合并后丢失 timeout 语义；
- 不把尚未运行的训练、仿真或硬件部署写成已验证结论；
- 不把 workspace 中的其他项目路径当成 legged_mjlab 的源码路径。

AMP 如果加入项目，应使用独立的 AMP adapter、AMP runner、motion loader 和 discriminator 组件。AMP 与 HIM 可以共享基础 observation/transition 合同，但不共享同一个专用 wrapper 文件。

### 3.1 MDP 是环境内部的 manager term 层

当前 `Go2Env` 缺少完整的 MDP 方法，这正是“文档看起来有训练结构，但训练实际上没有闭环”的主要原因。按照 mjlab、unitree_rl_mjlab、AMP_mjlab 和 legged_gym 的共同设计，MDP term 不应该直接操纵 MuJoCo 底层循环，而应该作为 `Go2Env` 的方法，再由同一个类把这些方法注册到 `ManagerBasedRlEnvCfg`。因此所有 Go2 MDP 逻辑都放在 `him_go2_env.py`，不另建项目级 `tasks/` 或 `mdp/`：

~~~text
legged_mjlab/envs/him_go2/
├── him_go2_env.py            # Go2Env、MDP methods、ManagerBasedRlEnvCfg 组装
├── him_go2_config.py         # legged_mjlab 配置层
└── go2_asset.py              # EntityCfg、actuator、collision、sensor 聚合类
~~~

`him_go2_env.py` 内部建议按方法分组：`_obs_*`、`_reward_*`、`_termination_*`、`_event_*`、`_curriculum_*`，以及 `_build_mjlab_cfg()`。`TaskRegistry` 只保存 `Go2Env`、环境配置和训练配置，不负责导入或计算 MDP term。

每个 `Go2Env` MDP method 的完整实现统一放在
`docs/逐文件可复制代码.md` 第 6 节的 `him_go2_env.py` 代码块中：observation term 返回
`[N, K]`，reward term 返回 `[N]`，termination term 返回 `[N]` 的 bool；time_out 通过
`TerminationTermCfg(time_out=True)` 单独标注。这里不再重复放置不完整的接口骨架。

manager 配置负责权重、噪声、scale、history 和 term 参数；`Go2Env` 的 MDP methods 负责读取 scene、sensor、command 和 action 状态。这样可以像 legged_gym 一样快速改奖励，又保留 mjlab 的 manager 生命周期。

推荐的 term 来源边界如下：

| Manager | 配置对象 | Go2 velocity 示例 | 输出 |
|---|---|---|---|
| Scene/Sensor | SceneCfg、ContactSensorCfg、RayCastSensorCfg | terrain_scan、feet_ground_contact、self_collision | 传感器数据 |
| Observation | ObservationGroupCfg、ObservationTermCfg | IMU、重力投影、command、关节状态、height scan、last action | actor/critic/amp group |
| Action | JointPositionActionCfg | 12 个关节目标位置 | actuator target |
| Command | UniformVelocityCommandCfg | twist：vx、vy、yaw rate、heading | command state |
| Event | EventTermCfg | reset pose、joint reset、push、friction、COM | 修改 episode 或模型状态 |
| Reward | RewardTermCfg | tracking、姿态、动作平滑、接触、碰撞 | [N] |
| Termination | TerminationTermCfg | timeout、姿态越界、base height、非法碰撞 | [N] bool |
| Curriculum | CurriculumTermCfg | terrain level、command range | 更新任务难度 |

### 3.2 Go2Env 内部的 MDP 与 manager 配置实现

下面代码展示 Go2Asset 与 MDP 的真正连接点。所有代码都写在 `him_go2_env.py` 的 `Go2Env` 类中：类方法先由资产类生成 EntityCfg 和 Scene sensor，再把同一个类里的 observation/reward/termination/event/curriculum methods 注册成 `ManagerBasedRlEnvCfg`。不再拆出独立配置文件或任何 `mdp/` 文件夹。

~~~python

class Go2Env(ManagerBasedRlEnv):


    @classmethod
    def _build_mjlab_cfg(
        cls,
        cfg,
        *,

        asset = Go2Asset(
            cfg,

            include_default_scene_sensors=True,
~~~

`require_effort_limits` 的默认值必须保持 `True`。只有 `test_go2_env.py` 的资源/配置 smoke test 可以显式传 `False`，而且该测试不能作为 release 或硬件部署验收；训练、播放和部署路径都使用默认的 `True`，直到配置补齐逐关节 effort limit。

在 HIM Go2 配置中，D=45 和 P=235 只能在固定 term 顺序下成立：

~~~text
actor / single step D:
  command(3) + base_ang_vel(3) + projected_gravity(3)
  + joint_pos(12) + joint_vel(12) + last_action(12)
  = 45

critic P:
  actor(45) + base_lin_vel(3) + height_scan(187)
  = 235
~~~

其中 critic 的 `[45:48]` 是 Go2 root/base COM 在机体坐标系下的线速度，单位为 `m/s`，由 `Go2Env._obs_root_lin_vel_b()` 提供；速度跟踪 reward 也必须使用同一 body-frame/root 语义。MJCF 的 `imu_lin_vel` 仍可作为原始传感器输入，但不能在未确认测点、坐标系和单位前直接冒充 `[45:48]`。

heading 可以作为 command manager 的内部状态用于重采样和 heading control，但不能未经切片直接拼入 actor observation；如果将 heading 第四维、foot contact、foot height 或其他 term 加入 policy/critic，就必须同步更新 D/P、HIMEstimator 固定切片、网络输入和部署配置。任务编译后应读取 ObservationManager 的实际 group shape，并在环境创建前断言实际值等于配置声明，不能只相信配置中的数字。

这里的 `Go2Env._build_events()`、`Go2Env._build_rewards()` 和 `Go2Env._build_terminations()` 应该保持纯配置方法，分别返回 dict[str, EventTermCfg]、dict[str, RewardTermCfg] 和 dict[str, TerminationTermCfg]。它们不能在配置构造阶段访问尚未编译的 env.data；真正的 term 方法只在 manager step 时接收 env 状态。

完整的 reward、termination、event 和 curriculum 配置已经和对应 term 方法放在
`docs/逐文件可复制代码.md` 第 6 节的 `him_go2_env.py` 完整代码块中。这里不再保留一个
缺少类上下文、需要从其他章节拼接的配置片段。

注意 termination reward 与 time_out 的关系：真正任务终止可以有 terminal penalty，但时间上限必须设置 time_out=True，由 wrapper 转换为 infos["time_outs"]，不能把所有 done 都当成可 bootstrap 的 timeout。

### 3.3 Go2Env 内部 MDP 方法的实现合同

以下方法全部继续写在 `legged_mjlab/envs/him_go2/him_go2_env.py` 的 `Go2Env` 类体内。`_obs_*` 方法只读取已经注册的 manager 数据；不要在 observation method 内自己创建传感器或读取 XML：

~~~python
import torch


class Go2Env:
    @staticmethod
    def _obs_builtin_sensor(env, sensor_name: str) -> torch.Tensor:
        # sensor_name 例如 robot/imu_ang_vel。
        value = env.scene.sensors[sensor_name].data
        value = value.to(dtype=torch.float32)
        if value.ndim == 1:
            value = value.unsqueeze(-1)
        # SensorManager 的实际 status API 以 mjlab==1.6.0 为准；这里的检查不能省略。
        status = env.sensor_manager.status(sensor_name)
        if status.disconnected or status.age_s > status.max_age_s:
            raise RuntimeError(f"stale or disconnected sensor: {sensor_name}")
        if not torch.isfinite(value).all():
            raise RuntimeError(f"non-finite sensor value: {sensor_name}")
        return value


    @staticmethod
    def _obs_projected_gravity(env) -> torch.Tensor:
        # 该 term 的合同是单位化、无量纲的 body-frame gravity direction。
        # 如果底层返回 m/s^2 原始加速度，必须先除以向量范数。
        gravity_b = env.scene["robot"].data.projected_gravity_b
        return gravity_b / torch.linalg.vector_norm(
            gravity_b, dim=-1, keepdim=True
        ).clamp_min(1e-6)


    @staticmethod
    def _obs_root_lin_vel_b(env) -> torch.Tensor:
        # HIM critic 的 [45:48] 明确使用 base/root COM 的 body-frame m/s 速度。
        return env.scene["robot"].data.root_lin_vel_b


    @staticmethod
    def _obs_generated_commands(env, command_name: str) -> torch.Tensor:
        # heading 可以由 command manager 内部使用，但 HIM actor 只消费 vx、vy、yaw_rate。
        return env.command_manager.get_command(command_name)[:, :3]


    @staticmethod
    def _obs_joint_pos_rel(env, asset_cfg) -> torch.Tensor:
        robot = env.scene[asset_cfg.name]
        joint_ids = asset_cfg.resolve_joint_ids(robot)
        return robot.data.joint_pos[:, joint_ids] - robot.data.default_joint_pos[:, joint_ids]


    @staticmethod
    def _obs_joint_vel_rel(env, asset_cfg) -> torch.Tensor:
        robot = env.scene[asset_cfg.name]
        joint_ids = asset_cfg.resolve_joint_ids(robot)
        return robot.data.joint_vel[:, joint_ids]


    @staticmethod
    def _obs_last_action(env) -> torch.Tensor:
        return env.action_manager.action


    @staticmethod
    def _obs_foot_contact(env, sensor_name: str) -> torch.Tensor:
        sensor = env.scene.sensors[sensor_name]
        found = sensor.data.found
        return found.to(dtype=torch.float32).flatten(start_dim=1)
~~~

真实 mjlab 版本的实体和传感器属性名可能略有差异，正式实现必须以 mjlab==1.6.0 的实际对象为准；但层次不能改变：Go2Env 的配置方法注册 sensor，Go2Env 的 MDP method 只消费 sensor，wrapper 只消费 observation dictionary。

同一个 `Go2Env` 类中的 `_reward_*` 方法返回 [N]，并且只使用 term 需要的实体/传感器：

~~~python
class Go2Env:
    @staticmethod
    def _reward_track_linear_velocity(env, command_name: str, std: float) -> torch.Tensor:
        command = env.command_manager.get_command(command_name)[:, :2]
        velocity = env.scene["robot"].data.root_lin_vel_b[:, :2]
        error = torch.sum(torch.square(command - velocity), dim=-1)
        return torch.exp(-error / (std * std))


    @staticmethod
    def _reward_action_rate_l2(env) -> torch.Tensor:
        action = env.action_manager.action
        previous = env.action_manager.prev_action
        return torch.sum(torch.square(action - previous), dim=-1)


    @staticmethod
    def _reward_hip_reduction(env, joint_names: tuple[str, ...]) -> torch.Tensor:
        robot = env.scene["robot"]
        joint_ids = robot.find_joints(joint_names)[0]
        hip_yaw = robot.data.joint_pos[:, joint_ids]
        reduction = env.cfg.control.hip_reduction
        return reduction * torch.sum(torch.square(hip_yaw), dim=-1)
~~~

事件和 curriculum 也继续写在同一个 `Go2Env` 类中，不再通过外部 `events.py` 或 `curriculums.py` 导入：

~~~python
class Go2Env:

    def _build_events(cfg, *, play: bool):
        return {
            "reset_root_state": EventTermCfg(

            "reset_joints": EventTermCfg(

                mode="reset",

            "random_push": EventTermCfg(

        }

    @staticmethod
    def _event_reset_root_state(env, env_ids=None):

        env.reset_root_state(env_ids)

    @staticmethod
    def _event_reset_joints(env, env_ids=None):
        env.reset_joint_state(env_ids)

    @staticmethod
    def _event_random_push(env, env_ids=None, max_velocity: float = 0.5):
        env.apply_push(env_ids, max_velocity=max_velocity)

    @staticmethod
    def _build_curriculums(cfg, *, play: bool):
        if play or not cfg.terrain.curriculum or cfg.play.disable_curriculum:
            return {}
        return {
            "terrain_level": CurriculumTermCfg(

            "command_range": CurriculumTermCfg(
                func=Go2Env._curriculum_command_range,
            ),
        }

    @staticmethod
    def _curriculum_terrain_level(env, env_ids=None):

~~~

上面的 `_event_*`、`_curriculum_*` 只是 manager callback；它们可以调用环境提供的 reset、terrain 和 command manager 接口，但不能直接改变 policy、runner 或 wrapper 状态。事件所需的配置通过 `EventTermCfg.params` 显式传入，不能依赖未定义的全局变量。

以上示例表达的是接口合同；例如 resolve_joint_ids()、root_lin_vel_b 的具体名字必须在实际 mjlab 版本中确认。不能为了让导入通过而给缺失的状态字段加默认零张量，否则会把模型/传感器映射错误隐藏到训练过程。

### 3.4 三个参考项目的取舍

本项目不是把三个项目的代码混在一起，而是分别吸收它们最稳定的边界：

| 参考项目 | 应吸收的设计 | 不应直接照搬的部分 |
|---|---|---|
| unitree_rl_mjlab | get_spec、mesh update、EntityCfg、SceneCfg.sensors、velocity env factory、mjlab task registration | 它使用的 rsl_rl wrapper 和 runner 版本；不能直接接项目内 HIM 7 元组 |
| AMP_mjlab | actor/critic/amp observation group、motion loader、AMP event、独立 AMP runner | AMP 专用 motion/discriminator 状态不能放进 HIM wrapper 或 Go2Asset |
| legged_gym/HIMLoco | Python 嵌套配置继承、TaskRegistry、简单 train/play CLI、奖励 term 的组织方式 | LeggedRobot 自己实现的 physics loop、asset load 和 reset；这些职责仍由 mjlab ManagerBasedRlEnv 承担 |

最终选择是：

~~~text
legged_gym 的配置体验
        +
mjlab 的 Entity / Scene / Sensor / Manager / Warp physics
        +
项目内 rsl_rl 的 PPO / HIM 算法后端
        +
AMP 独立的 motion/discriminator 分支
~~~

这也解释了当前的边界：Asset 仍然独立为 `go2_asset.py`，wrapper 仍然独立为算法协议适配层；但 Go2 专属的 MDP methods 按用户要求集中写在 `Go2Env` 类中，由该类统一管理 manager term 注册和环境生命周期。这里不再把 MDP 拆成额外文件。

## 4. 接口合同


### 4.1 维度和设备合同

设：

- N：并行环境数量；
- D：单步 policy observation 维度；
- H：history 长度；
- P：privileged observation 维度；
- A：动作维度；
- device：通常为 cuda:0，CPU smoke test 可以使用 cpu。

任务必须遵守：

| 数据 | 形状 | dtype | 说明 |
|---|---:|---|---|
| action | [N, A] | torch.float32 | policy 输出，进入环境前做裁剪 |
| 单步 policy observation | [N, D] | torch.float32 | 标准 PPO 的 actor 输入 |
| HIM history | [N, H, D] | torch.float32 | wrapper 内部保存的时序缓冲 |
| HIM actor observation | [N, H*D] | torch.float32 | 按约定的时间顺序展平 |
| privileged observation | [N, P] | torch.float32 | critic 或 estimator 使用 |
| reward | [N] 或 [N, 1] | torch.float32 | wrapper 统一成 [N] |
| terminated | [N] | torch.bool | 真正的任务终止 |
| truncated | [N] | torch.bool | 时间上限或外部截断 |
| dones | [N] | torch.bool | terminated 或 truncated，给 runner 的 episode mask |
| infos | dict | Python dict | 必须保留 timeout 和终止状态信息 |

所有环境张量必须在同一个 device 上。wrapper 不应在每个 step 中隐式转到 CPU，否则会造成 GPU 同步并破坏并行吞吐。

### 4.2 reset 合同

mjlab 原生环境建议提供：

~~~python
def reset(self, *, seed: int | None = None):
    obs_dict = {
        "actor": policy_obs,    # [N, D]，mjlab/unitree/AMP 的 canonical key
        "critic": critic_obs,   # [N, P]，可以为 None
    }
    extras = {"episode": {}}
    return obs_dict, extras
~~~

如果底层环境的 reset 只返回 obs_dict，wrapper 可以兼容这一版本差异，但最终对 runner 暴露的 reset 结果必须是固定协议。

### 4.3 step 合同

底层环境的推荐返回值是：

~~~python
obs_dict, rewards, terminated, truncated, infos = env.step(actions)
~~~

不要把 terminated 和 truncated 在底层直接合成一个值后丢弃原始字段。runner 的 episode mask 可以使用：

~~~python
dones = terminated | truncated
~~~

但 GAE 是否 bootstrap，需要由 infos["time_outs"] 或等价字段表达 timeout 语义。

这里有两层五元组，不能混写：

| 层 | 五元组 |
|---|---|
| mjlab/Gym 风格原始环境 | obs_dict, rewards, terminated, truncated, infos |
| rsl_rl.env.VecEnv 风格 wrapper | obs, privileged_obs, rewards, dones, infos |

HIMOnPolicyRunner 在当前内嵌 rsl_rl 中还需要 7 元组：

~~~text
(obs, privileged_obs, rewards, dones, infos,
 termination_ids, termination_privileged_obs)
~~~

其中 termination_privileged_obs 的最终形状固定为 [K, P]，K 等于 termination_ids.numel()。底层环境可以在 infos 中暂存 [N, P]，也可以直接暂存 [K, P]，但 wrapper 必须统一成最终的 [K, P]，不能二次索引。

观测组名称也要单独适配：mjlab、unitree_rl_mjlab 和 AMP_mjlab 的 canonical group 是 actor/critic/amp，而旧式 HIM 环境常用 policy/critic。项目 wrapper 的唯一映射应是 actor 或 policy 都可作为 actor 输入，最终向 rsl_rl 暴露统一的 obs；critic 始终映射为 privileged_obs；amp 只由 AMP 专用 adapter 消费，不能被普通 PPO/HIM 静默丢弃。

## 5. 配置层

### 5.1 BaseConfig

BaseConfig 提供两个行为：

1. 将嵌套 class 递归实例化，使每个配置实例拥有独立的子配置对象；
2. 将配置对象递归转换成 Python dict，供日志、CLI 覆盖和 RSL-RL runner 初始化。

目标实现模板：

~~~python
import inspect


def clone_container(value):
    if isinstance(value, dict):
        return {clone_container(k): clone_container(v) for k, v in value.items()}
    if isinstance(value, list):
        return [clone_container(item) for item in value]
    if isinstance(value, tuple):
        return tuple(clone_container(item) for item in value)
    if isinstance(value, set):
        return {clone_container(item) for item in value}
    return value


class BaseConfig:
    def __init__(self):
        self.init_member_classes(self)

    @classmethod
    def init_member_classes(cls, obj):
        for key in dir(obj):
            if key.startswith("__") or key == "__class__":
                continue

            value = getattr(obj, key)
            if inspect.isclass(value):
                instance = value()
                setattr(obj, key, instance)
                cls.init_member_classes(instance)
            elif isinstance(value, (dict, list, set)):
                setattr(obj, key, clone_container(value))

    def to_dict(self):
        def convert(obj):
            if not hasattr(obj, "__dict__"):
                return obj

            result = {}
            for key in dir(obj):
                if key.startswith("_"):
                    continue
                value = getattr(obj, key)
                if hasattr(value, "__dict__"):
                    result[key] = convert(value)
                elif isinstance(value, (dict, list, tuple, set)):
                    result[key] = clone_container(value)
                else:
                    result[key] = value
            return result

        return convert(self)
~~~

注意 dir 会暴露方法和继承字段。生产实现如果需要更严格的 schema，应增加字段过滤或改用 dataclass；但无论采用哪种方式，都必须保证 cfg_a.env 和 cfg_b.env 不共享可变字典、列表或集合。

## 6. Wrapper 适配层

### 6.1 wrapper 的职责

mjlab 环境返回的是面向 manager 的 observation dictionary，而 RSL-RL 通常需要固定位置的张量。wrapper 只做：

- observation group 取值和展平；
- reward、done、timeout 字段转换；
- history buffer 维护；
- terminal observation 捕获；
- 将底层属性透传给 runner。

wrapper 不应修改物理状态。可以把 mjlab 看成传感器总线，把 RSL-RL 看成控制器，wrapper 是协议转换器；转换器不应该反过来修改传感器的物理模型。

### 6.2 vec_env_wrapper.py

~~~python
from typing import Any


class VecEnvWrapper:
    def __init__(self, env):
        self.env = env

    def __getattr__(self, name: str) -> Any:
        return getattr(self.env, name)

    @property
    def device(self):
        return self.env.device

    def reset(self):
        return self.env.reset()

    def step(self, actions):
        return self.env.step(actions)

    def close(self):
        close = getattr(self.env, "close", None)
        if close is not None:
            close()
~~~

如果当前版本的 rsl_rl.env.VecEnv 是抽象基类，应让 VecEnvWrapper 继承该类并补齐其抽象属性；不要只靠 __getattr__ 伪造 runner 需要的字段。

代码观察：当前内嵌 rsl_rl.env.VecEnv 还声明了 reset(env_ids)、
get_observations() 和 get_privileged_observations() 等接口，而本文 wrapper 的 reset()
是面向 runner 的高层合同。正式落地时需要在 wrapper 中同时实现底层 VecEnv 抽象接口，
或在 adapter 中明确区分 reset(env_ids) 与初始 reset()，否则“5 元组形状正确”仍不足以构造 runner。

最小 adapter 合同的完整实现统一放在
`docs/逐文件可复制代码.md` 第 7–10 节：`VecEnvWrapper` 负责透传，
`RslRlVecEnvWrapper` 负责标准 5 元组，`HIMRslRlWrapper` 负责 history 和终止帧，
`AMPRslRlWrapper` 负责 AMP observation。这里不再拆出需要后续补全的 reset/get_observations
接口清单。

### 6.3 rsl_rl_wrapper.py：标准 PPO

标准 PPO 不需要 history encoder。它将 obs_dict 中的 actor 或 legacy policy group，以及 critic group，转成 runner 使用的二维 tensor；canonical mjlab 任务使用 actor/critic。

~~~python
import torch

from .vec_env_wrapper import VecEnvWrapper


def flatten_batch(value, *, name: str):
    if value is None:
        return None
    if not isinstance(value, torch.Tensor):
        raise TypeError(f"{name} must be a torch.Tensor or None")
    if value.ndim == 1:
        value = value.unsqueeze(0)
    if value.ndim > 2:
        value = value.reshape(value.shape[0], -1)
    if value.ndim != 2:
        raise ValueError(f"{name} must have shape [N, F], got {tuple(value.shape)}")
    return value


class RslRlVecEnvWrapper(VecEnvWrapper):
    def _split_obs(self, obs_dict):
        if not isinstance(obs_dict, dict):
            raise TypeError("observation must be a dict")

        # mjlab canonical key is actor; legacy HIM environments may use policy.
        actor = obs_dict.get("actor", obs_dict.get("policy"))
        if actor is None:
            raise TypeError("observation must contain actor or policy group")

        obs = flatten_batch(actor, name="actor/policy")
        privileged = flatten_batch(
            obs_dict.get("critic"),
            name="critic",
        )
        return obs, privileged

    def reset(self):
        result = self.env.reset()
        if isinstance(result, tuple) and len(result) == 2:
            obs_dict, _ = result
        else:
            obs_dict = result
        return self._split_obs(obs_dict)

    def step(self, actions):
        result = self.env.step(actions)
        if len(result) != 5:
            raise ValueError(
                "env.step must return "
                "(obs_dict, rewards, terminated, truncated, infos)"
            )

        obs_dict, rewards, terminated, truncated, infos = result
        obs, privileged = self._split_obs(obs_dict)
        terminated = terminated.to(dtype=torch.bool)
        truncated = truncated.to(dtype=torch.bool)
        dones = terminated | truncated
        rewards = rewards.reshape(-1)

        infos = dict(infos or {})
        # 真正终止和 timeout 同时出现时，不允许重复 bootstrap。
        infos["time_outs"] = truncated & ~terminated
        infos["terminated"] = terminated
        infos["truncated"] = truncated
        return obs, privileged, rewards, dones, infos
~~~

### 6.4 him_wrapper.py：HIM 专用适配

HIM wrapper 只负责维护时序 history，以及在自动 reset 覆盖状态前保留终止帧的 privileged observation。HIM estimator、latent loss 和 policy update 留在 rsl_rl。

以单步观测 D=45、history H=6 为例：

~~~text
obs_history_buf: [N, H, D] = [N, 6, 45]
actor observation: [N, H*D] = [N, 270]
privileged observation: [N, P]
~~~

当前 HIMActorCritic 的实现把展平后的前 D 个元素解释为当前帧，因此本文目标合同采用最新帧在前：

~~~text
obs_history_buf[:, 0]   = 最新帧
obs_history_buf[:, H-1] = 最旧帧
flatten 顺序            = [最新帧, ..., 最旧帧]
~~~

如果后续网络改成最旧帧在前，必须同时修改 wrapper、网络切片、checkpoint 说明和部署端，不能只修改文档。

目标实现模板：

~~~python
import torch

from .vec_env_wrapper import VecEnvWrapper


class HIMRslRlWrapper(VecEnvWrapper):
    def __init__(
        self,
        env,
        history_length: int,
        one_step_obs_dim: int,
        expected_privileged_obs_dim: int | None = None,
    ):
        super().__init__(env)
        self.history_length = history_length
        self.one_step_obs_dim = one_step_obs_dim
        # HIMOnPolicyRunner 使用这个旧式字段名构造 HIMActorCritic。
        self.num_one_step_obs = one_step_obs_dim
        self.num_obs = history_length * one_step_obs_dim
        self.num_privileged_obs = (
            expected_privileged_obs_dim
            if expected_privileged_obs_dim is not None
            else getattr(env, "num_privileged_obs", None)
        )
        self.num_actions = getattr(env, "num_actions", None)
        self.obs_history_buf = torch.zeros(
            self.num_envs,
            history_length,
            one_step_obs_dim,
            device=self.device,
            dtype=torch.float32,
        )
        self._privileged_obs = None

    @staticmethod
    def _flatten_group(value, name):
        if value is None:
            return None
        if not isinstance(value, torch.Tensor):
            raise TypeError(name + " must be a tensor")
        if value.ndim == 1:
            value = value.unsqueeze(0)
        if value.ndim > 2:
            value = value.reshape(value.shape[0], -1)
        if value.ndim != 2:
            raise ValueError(name + " must be [N, D]")
        return value

    def _split_obs(self, obs_dict):
        if not isinstance(obs_dict, dict):
            raise TypeError("native observation must be a dictionary")
        actor = obs_dict.get("actor", obs_dict.get("policy"))
        critic = obs_dict.get("critic", obs_dict.get("privileged"))
        if actor is None:
            raise KeyError("observation dictionary has no actor or policy group")
        return (
            self._flatten_group(actor, "actor"),
            self._flatten_group(critic, "critic"),
        )

    def _assert_him_contract(self, one_step_obs, privileged):
        if one_step_obs.shape != (self.num_envs, self.one_step_obs_dim):
            raise ValueError(
                "actor observation shape mismatch: "
                f"expected {(self.num_envs, self.one_step_obs_dim)}, "
                f"got {tuple(one_step_obs.shape)}"
            )
        if self.num_privileged_obs is not None and privileged is None:
            raise ValueError(
                "privileged observation is required by the HIM task"
            )
        if privileged is not None and privileged.shape[0] != self.num_envs:
            raise ValueError("critic observation batch dimension mismatch")
        if privileged is not None and privileged.shape[-1] != self.num_privileged_obs:
            raise ValueError(
                f"privileged observation width mismatch: "
                f"expected {self.num_privileged_obs}, got {privileged.shape[-1]}"
            )
        if not torch.isfinite(one_step_obs).all():
            raise FloatingPointError("actor observation contains NaN or Inf")
        if privileged is not None and not torch.isfinite(privileged).all():
            raise FloatingPointError("critic observation contains NaN or Inf")

    def _append_history(self, one_step_obs):
        if one_step_obs.shape[-1] != self.one_step_obs_dim:
            raise ValueError(
                f"expected {self.one_step_obs_dim}, "
                f"got {one_step_obs.shape[-1]}"
            )
        # HIMActorCritic 当前把展平后的前 D 个元素当作当前帧，
        # 因此最新帧放在第 0 个位置，旧帧向后移动。
        self.obs_history_buf[:, 1:] = self.obs_history_buf[:, :-1].clone()
        self.obs_history_buf[:, 0] = one_step_obs
        return self.obs_history_buf.reshape(self.num_envs, -1)

    def _reset_history(self, one_step_obs):
        # 冷启动时只写入当前帧，较旧帧保持零；这与当前项目 wrapper 的
        # reset 语义一致，也必须在部署端保持一致。
        self.obs_history_buf.zero_()
        self.obs_history_buf[:, 0] = one_step_obs
        return self.obs_history_buf.reshape(self.num_envs, -1)

    def reset(self, env_ids=None):
        result = self.env.reset(env_ids=env_ids)
        obs_dict = result[0] if isinstance(result, tuple) else result
        one_step_obs, privileged = self._split_obs(obs_dict)
        self._assert_him_contract(one_step_obs, privileged)
        if env_ids is None:
            obs = self._reset_history(one_step_obs)
        else:
            self.obs_history_buf[env_ids] = 0.0
            self.obs_history_buf[env_ids, 0] = one_step_obs[env_ids]
            obs = self.obs_history_buf.reshape(self.num_envs, -1)
        self._privileged_obs = privileged
        return obs, privileged

    def step(self, actions):
        pre_step_privileged = (
            None if self._privileged_obs is None
            else self._privileged_obs.clone()
        )

        obs_dict, rewards, terminated, truncated, infos = self.env.step(actions)
        one_step_obs, privileged = self._split_obs(obs_dict)
        self._assert_him_contract(one_step_obs, privileged)
        terminated = terminated.to(dtype=torch.bool)
        truncated = truncated.to(dtype=torch.bool)
        dones = terminated | truncated
        rewards = rewards.reshape(-1)
        infos = dict(infos or {})

        # mjlab 可能已经对 done 环境自动 reset；新 episode 的第一帧不能
        # 携带上一回合的 history。
        done_ids = torch.nonzero(dones, as_tuple=False).flatten()
        if done_ids.numel() > 0:
            self.obs_history_buf[done_ids] = 0.0
        obs = self._append_history(one_step_obs)

        # 最优先使用底层环境在 reset 前保存的 terminal observation。
        terminal_privileged = infos.get("termination_privileged_obs")
        if terminal_privileged is None:
            terminal_privileged = pre_step_privileged
        if terminal_privileged is None:
            terminal_privileged = privileged.clone()

        infos["time_outs"] = truncated & ~terminated
        infos["terminated"] = terminated
        infos["truncated"] = truncated
        self._privileged_obs = privileged

        termination_ids = done_ids
        if terminal_privileged.shape[0] == self.num_envs:
            termination_privileged_obs = terminal_privileged[termination_ids]
        elif terminal_privileged.shape[0] == termination_ids.numel():
            termination_privileged_obs = terminal_privileged
        else:
            raise ValueError(
                "termination privileged obs must have shape [N, P] or [K, P]"
            )
        return (
            obs,
            privileged,
            rewards,
            dones,
            infos,
            termination_ids,
            termination_privileged_obs,
        )
~~~

回退顺序必须写清楚：

1. 首选底层环境保存的终止时刻 privileged observation；
2. 没有终止帧字段时，使用 wrapper 在 step 前保存的状态；
3. 最后才使用当前 privileged，并在日志中标记 terminal frame 不可用。

回退值不等价于真正的终止后状态。HIM runner 如果依赖 terminal frame 训练 estimator，必须把真实终止帧和回退帧区分开。

### 7.2 go2_asset.py

资产层负责把 MJCF、EntityCfg、actuator、碰撞策略和传感器配置聚合到一个可复用的 Go2Asset 大类中。这个类是 Go2 机器人的唯一资产入口：Go2 环境不再自己读取 XML、重复声明 actuator 或重新拼传感器名称。

这里要先把 mjlab 的边界说清楚。当前 mjlab==1.6.0 的 EntityCfg 不是接收 xml_path，而是接收 spec_fn: Callable[[], mujoco.MjSpec]；EntityArticulationInfoCfg.actuators 是 tuple；SceneCfg.sensors 才是 ContactSensorCfg、RayCastSensorCfg 等 Python 运行时传感器的注册位置。因此，Go2Asset 可以在一个大类中管理这些对象，但不能把 SensorCfg 任意塞进 EntityCfg。

~~~text

├── collision_cfgs: tuple[CollisionCfg, ...]
├── scene_sensor_cfgs: tuple[SensorCfg, ...]
├── sensor_metadata: dict[str, SensorMetadata]
├── entity_cfg: EntityCfg
└── name maps: joints / bodies / sites / foot geoms
~~~

~~~python
        # Scene/MDP 中的 "robot/..." 引用一致；它不等同于 cfg.asset.name。
        self.entity_name = entity_name or self.Names.entity
        self.xml_path = self._resolve_xml_path(cfg.asset.xml)

        self.actuator_cfgs: list[BuiltinPositionActuatorCfg] = []
        self.collision_cfgs: list[CollisionCfg] = []
        self.scene_sensor_cfgs: list[SensorCfg] = []
        self.sensor_metadata: dict[str, SensorMetadata] = {}

        self._configure_default_actuators()
        self._configure_default_collisions()
        self._register_mjcf_sensor_metadata()
        if include_default_scene_sensors:
            self._configure_default_scene_sensors()

    # ------------------------------------------------------------------
    # Path and MJCF
    # ------------------------------------------------------------------

    def _resolve_xml_path(self, raw_xml: str | Path) -> Path:
        """Resolve config XML, including the current placeholder format."""

        raw = str(raw_xml).replace(
            "{LEGGED_MJLAB_ROOT_DIR}",
            str(project_root()),
        )
        path = Path(raw).expanduser()
        if not path.is_absolute():
            path = project_root() / path
        path = path.resolve()
        if not path.is_file():
            raise FileNotFoundError(f"Go2 MJCF does not exist: {path}")
        return path

    def _collect_xml_assets(self, spec: mujoco.MjSpec) -> dict[str, bytes]:
        """Embed mesh files under the XML compiler meshdir.

        The XML currently declares meshdir="assets". The exact MjSpec asset
        assignment is version-sensitive and must be checked after upgrades.
        """

        mesh_root = (self.xml_path.parent / spec.meshdir).resolve()
        if not mesh_root.is_dir():
            raise FileNotFoundError(
                f"meshdir={spec.meshdir!r} resolves to missing directory: "
                f"{mesh_root}"
            )
        return {
            path.relative_to(mesh_root).as_posix(): path.read_bytes()
            for path in mesh_root.rglob("*")
            if path.is_file()
        }

    def build_spec(self) -> mujoco.MjSpec:
        """Return a fresh MjSpec for every Entity construction."""

        spec = mujoco.MjSpec.from_file(str(self.xml_path))
        self.validate_canonical_spec(spec)
        spec.assets = self._collect_xml_assets(spec)
        return spec

    def validate_canonical_spec(self, spec: mujoco.MjSpec) -> None:
        if self.xml_path.name != "go2.xml":
            raise ValueError(
                f"unsupported Go2 asset source: {self.xml_path}; "
                "expected canonical go2.xml"
            )
        if len(spec.actuators) != 0:
            raise ValueError(
                "canonical go2.xml must not contain MJCF actuators; "
                "scene_go2.xml or another motorized model was selected"
            )

    # ------------------------------------------------------------------
    # Actuators and collision
    # ------------------------------------------------------------------

    def _configure_default_actuators(self) -> None:
        stiffness = self.cfg.control.stiffness
        damping = self.cfg.control.damping
        armature = getattr(self.cfg.asset, "armature", None)
        effort_limit = getattr(self.cfg.asset, "effort_limit", None)

        for group_name, target_names_expr in self.Names.joint_groups.items():
            self.add_actuator(
                BuiltinPositionActuatorCfg(
                    target_names_expr=target_names_expr,
                    stiffness=stiffness[group_name],
                    damping=damping[group_name],
                    armature=armature,
                    effort_limit=effort_limit,
                )
            )

    def _configure_default_collisions(self) -> None:
        self.add_collision(
            CollisionCfg(
                geom_names_expr=(self.COLLISION_REGEX,),
                contype=1,
                conaffinity=1,
                condim={
                    self.FOOT_GEOM_REGEX: 3,
                    self.COLLISION_REGEX: 1,
                },
                priority=0,
                friction={self.FOOT_GEOM_REGEX: (0.6,)},
            )
        )

    def add_actuator(self, actuator_cfg: BuiltinPositionActuatorCfg) -> None:
        """Append one actuator group to the EntityCfg actuator tuple."""

        self.actuator_cfgs.append(actuator_cfg)

    def add_collision(self, collision_cfg: CollisionCfg) -> None:
        """Append one collision policy to the EntityCfg collision tuple."""

        self.collision_cfgs.append(collision_cfg)

    # Sensors
    # ------------------------------------------------------------------

                mount=self.Names.imu_site,

                unit="m/s^2",
                shape=(3,),

                channels=("value",),

    def _configure_default_scene_sensors(self) -> None:
        """Register Go2-specific contact sensing; terrain scan is task-level."""

        self.add_foot_contact_sensor()

    def _register_metadata(self, metadata: SensorMetadata) -> None:
        if not metadata.name:
            raise ValueError("sensor metadata name must not be empty")
        if metadata.name in self.sensor_metadata:
            raise ValueError(f"duplicate Go2 sensor metadata: {metadata.name}")
        self.sensor_metadata[metadata.name] = metadata

    def _validate_scene_sensor_metadata(self) -> None:
        configured = {sensor.name for sensor in self.scene_sensor_cfgs}
        described = set(self.sensor_metadata)
        missing = configured - described
        if missing:
            raise ValueError(
                "required Scene sensors have no metadata: "
                f"{sorted(missing)}"
            )
        for name in configured:
            metadata = self.sensor_metadata[name]
            if metadata.required and not metadata.channels:
                raise ValueError(
                    f"required sensor has no channel contract: {name}"
                )

    def add_sensor(
        self,
        sensor_cfg: SensorCfg,
        *,
        metadata: SensorMetadata,
        replace: bool = False,
    ) -> None:
        """Add a Scene-level SensorCfg and optionally its metadata."""

        existing = {
            sensor.name: index
            for index, sensor in enumerate(self.scene_sensor_cfgs)
        }
        if not sensor_cfg.name:
            raise ValueError("Scene sensor name must not be empty")
        if sensor_cfg.name in existing and not replace:
            raise ValueError(f"duplicate Scene sensor: {sensor_cfg.name}")

        if sensor_cfg.name in existing:
            self.scene_sensor_cfgs[existing[sensor_cfg.name]] = sensor_cfg
        else:
            self.scene_sensor_cfgs.append(sensor_cfg)

        if metadata.name != sensor_cfg.name:
            raise ValueError("sensor config and metadata names must match")
        if replace:
            self.sensor_metadata.pop(metadata.name, None)
        self._register_metadata(metadata)

    def add_foot_contact_sensor(self) -> None:

        self.add_sensor(

                ),

                reduce="netforce",
                track_air_time=True,

            metadata=SensorMetadata(
                name="feet_ground_contact",
                mount="FL/FR/RL/RR foot geoms",
                frame="world",
                unit="found:bool, force:N",
                shape=(16,),
                source="Scene ContactSensorCfg",
                channels=("found", "force"),
                field_shapes=(("found", (4,)), ("force", (4, 3))),
                max_age_s=0.02,
            ),
        )

    def add_terrain_scan_sensor(
        self,
        *,
        frame_body: str | None = None,
        size: tuple[float, float] = (1.6, 1.0),
        resolution: float = 0.1,

        """Add a task-selectable height ray sensor to SceneCfg.sensors."""

        self.add_sensor(
            RayCastSensorCfg(
                name="terrain_scan",

    def build_scene_sensors(self) -> tuple[SensorCfg, ...]:
        """Return fresh Scene sensor configs for SceneCfg.sensors."""

        return tuple(self.scene_sensor_cfgs)

    # ------------------------------------------------------------------
    # Entity and scene outputs
    # ------------------------------------------------------------------

    @staticmethod
    def _matches(patterns: tuple[str, ...], names: tuple[str, ...]) -> set[str]:
        return {
            name
            for name in names
            if any(re.fullmatch(pattern, name) for pattern in patterns)
        }

    def _validate_actuator_contract(
        self,
        *,
        entity: Entity,
        require_effort_limits: bool,
    ) -> None:
        if not self.actuator_cfgs:
            raise ValueError("Go2 must define at least one actuator group")

        covered: set[str] = set()
        for actuator_cfg in self.actuator_cfgs:
            if not actuator_cfg.target_names_expr:
                raise ValueError("actuator target_names_expr must not be empty")
            if not math.isfinite(actuator_cfg.stiffness) or actuator_cfg.stiffness <= 0:
                raise ValueError("actuator stiffness must be finite and positive")
            if not math.isfinite(actuator_cfg.damping) or actuator_cfg.damping < 0:
                raise ValueError("actuator damping must be finite and non-negative")
            if require_effort_limits and actuator_cfg.effort_limit is None:
                raise ValueError(
                    "effort_limit is required before hardware or release validation"
                )
            if actuator_cfg.effort_limit is not None and (
                not math.isfinite(actuator_cfg.effort_limit)
                or actuator_cfg.effort_limit <= 0
            ):
                raise ValueError("effort_limit must be finite and positive")
            matched = self._matches(
                actuator_cfg.target_names_expr,
                tuple(entity.joint_names),
            )
            if not matched:
                raise ValueError(
                    "actuator pattern matched no Go2 joint: "
                    f"{actuator_cfg.target_names_expr}"
                )
            overlap = covered & matched
            if overlap:
                raise ValueError(
                    f"overlapping actuator joint patterns: {sorted(overlap)}"
                )
            covered |= matched

        expected = set(entity.joint_names)
        if tuple(entity.joint_names) != self.Names.joint_order:
            raise ValueError(
                "Go2 joint order mismatch: "
                f"{tuple(entity.joint_names)}"
            )
        missing = expected - covered
        if missing:
            raise ValueError(f"unactuated Go2 joints: {sorted(missing)}")

    def _validate_collision_contract(self, entity: Entity) -> None:
        geom_names = tuple(entity.geom_names)
        matched = self._matches((self.COLLISION_REGEX,), geom_names)
        if not matched:
            raise ValueError("Go2 collision pattern matched no geoms")

        missing_feet = set(self.Names.foot_geoms) - set(geom_names)
        if missing_feet:
            raise ValueError(f"missing Go2 foot collision geoms: {sorted(missing_feet)}")

    def _validate_actuator_patterns_against(
        self,
        expected_joint_names: tuple[str, ...],
    ) -> None:
        covered: set[str] = set()
        for actuator_cfg in self.actuator_cfgs:
            matched = self._matches(
                actuator_cfg.target_names_expr,
                expected_joint_names,
            )
            if not matched:
                raise ValueError(
                    f"actuator pattern matched no joint: "
                    f"{actuator_cfg.target_names_expr}"
                )
            overlap = covered & matched
            if overlap:
                raise ValueError(
                    f"overlapping actuator patterns: {sorted(overlap)}"
                )
            covered |= matched
        if covered != set(expected_joint_names):
            raise ValueError(
                "actuator patterns do not cover exactly the expected joints"
            )

    def _validate_compiled_collision_matrix(self) -> None:
        entity = Entity(self.build_entity_cfg())
        model = entity.compile()
        if model.ngeom == 0:
            raise ValueError("compiled Go2 model has no geoms")
        for geom_id in range(model.ngeom):
            name = mujoco.mj_id2name(
                model,
                mujoco.mjtObj.mjOBJ_GEOM,
                geom_id,
            )
            if not name or not re.fullmatch(self.COLLISION_REGEX, name):
                continue
            if int(model.geom_contype[geom_id]) != 1:
                raise ValueError(f"collision contype mismatch: {name}")
            if int(model.geom_conaffinity[geom_id]) != 1:
                raise ValueError(f"collision conaffinity mismatch: {name}")
            expected_condim = (
                3 if re.fullmatch(self.FOOT_GEOM_REGEX, name) else 1
            )
            if int(model.geom_condim[geom_id]) != expected_condim:
                raise ValueError(f"collision condim mismatch: {name}")
            if not math.isfinite(float(model.geom_friction[geom_id, 0])):
                raise ValueError(f"collision friction is not finite: {name}")

    def build_entity_cfg(self) -> EntityCfg:
        """Return a fresh EntityCfg; spec_fn creates a fresh MjSpec."""

        init_state = EntityCfg.InitialStateCfg(
            pos=tuple(self.cfg.init_state.pos),
            joint_pos=dict(self.cfg.init_state.default_joint_angles),
            joint_vel={".*": 0.0},
        )
        return EntityCfg(
            init_state=init_state,
            spec_fn=self.build_spec,
            sort_actuators=True,
            collisions=tuple(self.collision_cfgs),
            articulation=EntityArticulationInfoCfg(
                actuators=tuple(self.actuator_cfgs),
            ),
        )

    def build_scene_cfg(self) -> SceneCfg:
        """Convenience output for the Go2 environment config builder."""

        return SceneCfg(
            num_envs=self.cfg.env.num_envs,
            env_spacing=self.cfg.env.env_spacing,
            entities={self.entity_name: self.build_entity_cfg()},
            sensors=self.build_scene_sensors(),
        )

    def preflight(self, require_effort_limits: bool = True) -> dict[str, Any]:
        self._validate_actuator_patterns_against(self.Names.joint_order)
        self._validate_scene_sensor_metadata()
        self._validate_compiled_collision_matrix()
        return self.validate(
            require_effort_limits=require_effort_limits
        )

    def validate(
        self,
        *,
        require_effort_limits: bool = False,
    ) -> dict[str, Any]:
        """Audit assembled EntityCfg and compile a diagnostic model.

        This validates the asset assembly boundary only. It does not validate
        reset/step, Scene sensor matching, policy outputs, or hardware safety.
        Set require_effort_limits=True before release or hardware work.
        """

        entity = Entity(self.build_entity_cfg())
        self._validate_actuator_contract(
            entity=entity,
            require_effort_limits=require_effort_limits,
        )
        self._validate_collision_contract(entity)
        model = entity.compile()
        return {
            "xml": str(self.xml_path),
            "nq": model.nq,
            "nv": model.nv,
            "nu": model.nu,
            "njnt": model.njnt,
            "nbody": model.nbody,
            "nsite": model.nsite,
            "entity_actuators": entity.num_actuators,
            "entity_collision_cfgs": len(self.collision_cfgs),
            "scene_sensors": tuple(sensor.name for sensor in self.scene_sensor_cfgs),
            "mjcf_sensors": tuple(self.sensor_metadata),
        }
~~~

这个总类解决了“文件里有很多零散 builder”的问题：默认执行器、默认碰撞、MJCF 固有传感器、Scene 级接触传感器和可选 terrain scan 都从同一个对象产生。与此同时，build_entity_cfg() 和 build_scene_sensors() 的输出边界仍然与 mjlab 的 API 一致。

### 7.2.2 配置解析、MJCF 导入和传感器导入规则

Go2Asset 的构造函数不应该导入 HimGo2RoughCfg，也不应该依赖某一个训练算法。它接收已经实例化的通用配置对象，按下面的规则解析：

| 配置来源 | Asset 输出 | 说明 |
|---|---|---|
| cfg.asset.xml | xml_path、MjSpec | 解析占位符、检查文件、读取 compiler.meshdir 下的 mesh |
| cfg.asset.name | 资产描述名 | 不用作 Scene namespace；Scene namespace 由 entity_name 决定 |
| cfg.init_state.pos | EntityCfg.InitialStateCfg.pos | 位置单位为 m |
| cfg.init_state.default_joint_angles | InitialStateCfg.joint_pos | 字典 key 必须完整覆盖 12 个 joint |
| cfg.control.stiffness | BuiltinPositionActuatorCfg.stiffness | 按 hip/thigh/calf 组映射 |
| cfg.control.damping | BuiltinPositionActuatorCfg.damping | 与 stiffness 使用相同 joint regex |
| cfg.asset.armature / effort_limit | actuator armature/effort | 缺失 effort 只能做仿真诊断，不能宣称硬件安全 |
| cfg.asset.penalize_contacts_on | collision/reward 名称筛选 | 只影响任务策略，不直接覆盖所有 MJCF geom |
| cfg.env.num_envs/env_spacing | SceneCfg | 只在 Go2Env 组装 Scene 时使用 |
| cfg.terrain | TerrainEntityCfg 和 terrain scan | rough/flat 是任务配置，不写进纯机器人实体 |

配置解析必须是单向的：

~~~text
BaseConfig instance
  -> Go2Asset(cfg)
       -> Path / MjSpec / mesh bytes
       -> actuator_cfgs
       -> collision_cfgs
       -> native sensor metadata
       -> Scene sensor cfgs
       -> EntityCfg + SceneCfg.sensors
~~~

不要在 Asset 中读取 train_cfg，也不要把 PPO/HIM 的 history_length 写入 ContactSensorCfg。HIM 的 history 是 observation/wrapper 合同；传感器的 history_length 只表示该 sensor 自己保留的物理历史。

传感器分成两类：

1. MJCF 原生传感器：已经位于 go2.xml 的 sensor section，由 MjSpec 导入。例如 imu_ang_vel、imu_lin_vel、imu_lin_acc、root_angmom。它们不再重复构造 ContactSensorCfg；MDP 通过统一的 builtin sensor term 读取。
2. Scene 运行时传感器：依赖 terrain、实体 namespace 或接触匹配，由 Go2Asset.add_sensor() 生成并最终放入 SceneCfg.sensors。例如足端接触、self collision、terrain scan。

真实注册路径应当是：

~~~text
go2.xml <sensor>
    -> MjSpec
    -> mjlab builtin sensor namespace: robot/imu_ang_vel

Go2Asset.add_sensor(ContactSensorCfg/RayCastSensorCfg)
    -> SceneCfg.sensors
    -> SensorManager
    -> MDP observation/reward term
~~~

sensor name 必须全局稳定且不重复。Asset 层负责名称、挂载点、单位、shape metadata；Scene/MDP 层负责运行时匹配、数据读取、NaN/Inf 检查和观测拼接。

### 7.2.3 如何在 Go2Env 配置组装阶段添加传感器

Go2Asset 支持集中注册，但 terrain scan 仍由任务决定。平地任务可以只使用足端接触；rough terrain 任务再显式添加 ray sensor：

~~~python
asset = Go2Asset(
    cfg,
    entity_name="robot",
    include_default_scene_sensors=True,
)
asset.add_terrain_scan_sensor(
    frame_body=asset.Names.base_body,
    size=(1.6, 1.0),
    resolution=0.1,
    max_distance=5.0,
    debug_vis=True,
)

scene_cfg = asset.build_scene_cfg()
scene_cfg.entities["robot"] = asset.build_entity_cfg()
scene_cfg.sensors = asset.build_scene_sensors()
~~~

自定义传感器也走同一入口：

~~~python
asset.add_sensor(
    ContactSensorCfg(
        name="self_collision",
        primary=ContactMatch(
            mode="subtree",
            pattern="base_link",
            entity="robot",
        ),
        secondary=ContactMatch(
            mode="subtree",
            pattern="base_link",
            entity="robot",
        ),
        fields=("found", "force"),
        reduce="none",
        history_length=4,
    ),
    metadata=SensorMetadata(
        name="self_collision",
        mount=Go2Asset.Names.base_body,
        frame="world",
        unit="found:bool, force:N",
        shape=(16,),
        source="Scene ContactSensorCfg",
        channels=("found", "force"),
        field_shapes=(("found", (4,)), ("force", (4, 3))),

)
~~~

ContactSensorCfg.history_length 是传感器内部缓存，不是 HIM 的 observation history；HIM 的 [N, H, D] 历史仍由 observation/wrapper 合同维护。

### 7.2.4 资产与传感器的边界

可以放进 Go2Asset 的内容：

- go2.xml 的路径、mesh 资源和 MjSpec 构建；
- Go2 的 joint/body/site/geom 名称合同；
- BuiltinPositionActuatorCfg；
- CollisionCfg；
- Go2 自带的 MJCF sensor metadata；
- Go2 默认足端接触 SensorCfg；
- 提供给 Go2Env 配置组装阶段的 add_sensor()、add_terrain_scan_sensor()。

不应放进 Go2Asset 的内容：

- actor/critic observation history、noise、delay；
- reward、termination、command 和 curriculum；
- HIM latent、AMP discriminator 或 runner；
- 将 SensorCfg 私自写入 EntityCfg；
- 读取 Scene 状态后计算 reward。

本地 AMP_mjlab 和 unitree_rl_mjlab 的实现都遵循一个重要事实：机器人实体通过 EntityCfg 放入 SceneCfg.entities，terrain raycast 和接触匹配通过 SceneCfg.sensors 注册。Go2Asset 可以把两类配置聚合在一个类里提供，但最终仍要分别输出给 EntityCfg 和 SceneCfg。

参考项目中的部分 asset helper 使用了 mjlab 1.2 时代的 update_assets()；当前 legged_mjlab 依赖的是 mjlab==1.6.0，安装包中不能假定该 helper 存在。因此本文模板使用当前版本可见的 MjSpec.assets 绑定方式，最终必须以 MjSpec.compile() 的结果验证 mesh 相对路径，不能只复制参考项目的 import。

当前 go2.xml 已声明 imu site、imu_ang_vel、imu_lin_vel、imu_lin_acc、root_angmom，并包含 12 个关节、四个足端 site 和足端 collision geom；当前 go2.xml 没有 <actuator>，因此执行器必须通过 EntityArticulationInfoCfg 注入。scene_go2.xml 是另一份包含 motor 和额外 sensor 的完整模型，不能与 go2.xml 的 sensor source of truth 混用。

目标实现中的 Go2Asset.validate() 会先构造 Entity(self.build_entity_cfg())，再检查 actuator 覆盖、刚度/阻尼/effort finite、collision 匹配和最终 MJCF 编译；它仍不能替代 Scene sensor 的实际匹配、环境 reset/step、wrapper、runner 或硬件安全验证。传感器的 required、finite_required 和 max_age_s metadata 必须由 Scene/runtime 层消费：匹配为空、数据过期或出现 NaN/Inf 时，应 fail-closed，阻止当前动作继续进入 actuator。

当前 Go2 配置没有 effort_limit 字段，因此普通仿真诊断可以使用 validate(require_effort_limits=False)，但发布或真实硬件前必须补齐每组/每关节 effort limit，并使用 validate(require_effort_limits=True)。当前代码尚未落地这个大类，所有运行结果仍属于未执行/未验证。

### 7.2.5 Asset 安全校验必须是 fail-closed

Go2Asset 的 validate() 不是“能 compile 就算通过”。为了避免把带 motor 的 scene_go2.xml 误当成无 actuator 的 canonical asset，资产导入必须先执行源文件校验：

~~~python
def validate_canonical_spec(self, spec: mujoco.MjSpec) -> None:
    if self.xml_path.name != "go2.xml":
        raise ValueError(
            f"unsupported Go2 asset source: {self.xml_path}; "
            "expected canonical go2.xml"
        )
    if len(spec.actuators) != 0:
        raise ValueError(
            "canonical go2.xml must not contain MJCF actuators; "
            "scene_go2.xml or another motorized model was selected"
        )
~~~

这个校验必须在注入 BuiltinPositionActuatorCfg 之前执行。允许在 Entity 层注入一套 actuator，但禁止“原 XML 已有 motor，再额外注入一套 motor”的双重控制路径。

release/startup 的唯一入口应当是 Go2Asset.preflight()，由它串行执行 canonical source、MJCF allowlist、actuator、collision 和 Scene sensor 检查；任何一步失败都不得创建 ManagerBasedRlEnv：

~~~python
CANONICAL_GO2_XML = (
    project_root() / "resources/robots/unitree_go2/xmls/go2.xml"
).resolve()

EXPECTED_JOINTS = (
    "FL_hip_joint", "FL_thigh_joint", "FL_calf_joint",
    "FR_hip_joint", "FR_thigh_joint", "FR_calf_joint",
    "RL_hip_joint", "RL_thigh_joint", "RL_calf_joint",
    "RR_hip_joint", "RR_thigh_joint", "RR_calf_joint",
)

EXPECTED_MJCF_SENSORS = (
    "imu_ang_vel",
    "imu_lin_vel",
    "imu_lin_acc",
    "root_angmom",
)


def preflight(self, require_effort_limits: bool = True):
    if self.xml_path != CANONICAL_GO2_XML:
        raise ValueError("Go2 release requires the canonical XML path")
    spec = self.build_spec()
    if tuple(j.name for j in spec.joints) != EXPECTED_JOINTS:
        raise ValueError("Go2 joint allowlist/order mismatch")
    if tuple(s.name for s in spec.sensors) != EXPECTED_MJCF_SENSORS:
        raise ValueError("Go2 MJCF sensor allowlist mismatch")
    for sensor_name in EXPECTED_MJCF_SENSORS:
        metadata = self.sensor_metadata.get(sensor_name)
        if metadata is None or not metadata.channels:
            raise ValueError(
                f"missing MJCF sensor metadata/channel contract: {sensor_name}"
            )
    self._validate_actuator_patterns_against(EXPECTED_JOINTS)
    self._validate_scene_sensor_metadata()
    self._validate_compiled_collision_matrix()
    return self.validate(
        require_effort_limits=require_effort_limits
    )
~~~

开发阶段可以提供 allow_custom_xml=True 的仿真诊断模式，但 release/hardware 模式必须固定绝对路径、文件内容 hash、mesh 清单和 joint/body/site/geom allowlist。这样另一份同名 go2.xml 不能通过仅靠文件名的检查。

每个 actuator pattern 必须满足以下条件：

~~~text
expected_joint_names = canonical Go2 12-joint order
  [FL_hip, FL_thigh, FL_calf,
   FR_hip, FR_thigh, FR_calf,
   RL_hip, RL_thigh, RL_calf,
   RR_hip, RR_thigh, RR_calf]

for each actuator group:
  matched = regex(group.target_names_expr, expected_joint_names)
  require len(matched) > 0
  require every matched joint is in expected_joint_names
  require no joint is covered by two groups

require union(all matched) == set(expected_joint_names)
require compiled actuator order == expected joint order
require num_actions == 12
~~~

只验证“union 覆盖了所有 joint”还不够：零匹配、重叠匹配、动作顺序错位都必须直接抛错。_validate_actuator_patterns_against() 应记录每个 joint 被哪些 group 命中，并要求每个 joint 恰好命中一次。每个关节还必须有可审计的 position、velocity、effort/current、temperature 和 action-rate limit；仿真配置中的单一 effort_limit 不能被当成真实电机逐关节限制。

碰撞校验也必须检查编译后的模型，而不是只检查名称存在：

~~~text
for each expected collision geom:
  require contype/conaffinity/condim == configured value
  require foot friction is within the configured range
  require unexpected visual geom is not enabled as a collision geom

build a contact matrix for:
  foot <-> terrain
  base/penalized body <-> terrain
  robot self-collision
require the matrix matches the task policy
~~~

当前配置中已有 terminate_after_contacts_on=["base"] 的语义，因此任务终止配置必须显式包含 base contact term；不能只写 bad_orientation 和 base height，却继续宣称“机身接触会终止”。碰撞奖励、终止条件和硬件安全接触策略必须分别命名、分别测试。

所有 MJCF 和 Scene sensor 都要有唯一的 name、namespace、shape、unit、frame、sample timestamp/step id、max_age 和断连语义。required sensor 匹配失败、数据过期、NaN/Inf 或 step id 不连续时，runtime safety gate 必须锁存安全态，禁止新的 actuator command 继续下发。抛出 Python exception 只适用于仿真诊断，不等于真实硬件的 fail-closed 控制器。

动作链应当只有一个可审计的 pre-actuator safety gate：

~~~text
sensor health / observation finite
  -> policy output finite
  -> normalization finite
  -> action scale
  -> joint-wise position/velocity/effort/rate limits
  -> watchdog/deadline check
  -> actuator command

任意一步失败
  -> latch fault
  -> zero-torque / damping / hold-safe state
  -> 只有显式人工或上层恢复条件满足时才允许解锁
~~~

RL 的 episode timeout 只用于 GAE 的 value bootstrap，不能代替控制 watchdog。策略线程卡死、通信丢包、传感器断连和 deadline 超时必须由独立的 runtime/hardware safety layer 处理；当前仓库没有这层硬件实现，因此仍然不能宣称可直接上机。

### 7.3 him_go2_env.py

`Go2Env` 负责将 Go2 asset、场景以及同一个类中的 commands、observations、rewards、terminations、events 和 curriculums 方法组装成 mjlab 的 manager-based 环境。下面只展示环境类的生命周期边界；具体 MDP 方法见前面的 `Go2Env._obs_*`、`_reward_*`、`_termination_*` 和 `_build_*` 实现，它们都位于这个文件中：

~~~python
from mjlab.envs import ManagerBasedRlEnv


class Go2Env(ManagerBasedRlEnv):
    def __init__(self, cfg, sim_device="cuda:0", headless=False, play=False):
        self.cfg = cfg
        super().__init__(
            cfg=type(self)._build_mjlab_cfg(cfg, play=play),
            device=sim_device,
            render_mode=None if headless else "human",
        )

    def step(self, actions):
        # 这里先拒绝非有限 policy 输出；最终 actuator target 的 gate
        # 必须挂在 mjlab ActionManager 的 scale/limit 之后，不能只在这里检查原始 actions。
        self.safety_gate.check_policy_output(actions)
        return super().step(actions)

    def _pre_actuator_gate(self, actuator_command):
        # 伪代码：需要接入 mjlab 1.6.0 的最终 actuator-command hook。
        # 真实硬件部署进程还要执行同等或更严格的 gate。
        return self.safety_gate.validate(
            actuator_command,
            observation_finite=self.observation_manager.is_finite(),
            sensor_health=self.sensor_manager.health(),
            deadline_ok=self.watchdog.deadline_ok(),
        )

    # _reward_hip_reduction 等方法已经由 _build_mjlab_cfg 注册到 RewardManager。
    # 环境类同时提供 manager 生命周期和 MDP term，不另建 mdp 模块。
~~~

例如 `Go2Env._reward_hip_reduction(env, ...)` 返回 `[N]`，并由 `Go2Env._build_mjlab_cfg()` 以 `RewardTermCfg(func=Go2Env._reward_hip_reduction, ...)` 注册。reward method 的返回值必须保留 batch 维度，不能在 term 内部调用 mean，否则会把并行环境维度提前消掉。

safety_gate.validate() 失败时必须锁存 fault，并输出预先定义的 zero-torque、damping 或 hold-safe 命令；不能让异常被捕获后继续使用原始 actions。watchdog 周期、deadline、线程优先级、原子命令交接、锁顺序、关闭/恢复条件和最大安全响应延迟属于部署实现合同，当前仓库没有实现，不能由仿真 episode timeout 代替。

环境 step 的内部顺序建议固定为：

~~~text
原始 policy output finite check
  -> 动作裁剪
  -> action scale / joint target
  -> pre-actuator safety gate（最终 joint target/effort/rate limit）
  -> decimation 次数的执行器与物理步进
  -> 更新缓存的动力学量
  -> 计算 policy/critic observation
  -> 计算 reward
  -> 计算 terminated/truncated
  -> 保存 terminal observation
  -> 对 done 环境 reset
~~~

## 8. task_registry.py

### 8.1 注册表职责

TaskRegistry 只保存三类信息：

- task_classes[name]：环境 class 或环境 factory；
- env_cfgs[name]：环境配置 class；
- train_cfgs[name]：算法/runner 配置 class。

它不应持有跨任务共享的可变环境实例，也不应在注册阶段启动仿真。

MDP 不属于注册表职责。`task_registry.register("him_go2", Go2Env, ...)` 注册的是环境入口；真正的 MDP 组装发生在 `Go2Env` 初始化时调用的 `Go2Env._build_mjlab_cfg()`，该方法直接引用同一个类中的 observation、reward、termination、event 和 curriculum methods。这样既保留 legged_gym 的任务名和 CLI 体验，也不会因为 registry 的存在重新引入项目级 `tasks/` 或 `mdp/` 目录。

### 8.2 目标实现

~~~python
import os

from legged_mjlab.wrappers import (
    HIMRslRlWrapper,
    RslRlVecEnvWrapper,
)
from legged_mjlab.utils.helpers import class_to_dict


class TaskRegistry:
    def __init__(self):
        self.task_classes = {}
        self.env_cfgs = {}
        self.train_cfgs = {}

    def register(self, name, task_class, env_cfg, train_cfg):
        if name in self.task_classes:
            raise ValueError(f"task already registered: {name}")
        self.task_classes[name] = task_class
        self.env_cfgs[name] = env_cfg
        self.train_cfgs[name] = train_cfg

    def get_cfgs(self, name):
        if name not in self.task_classes:
            raise KeyError(f"unknown task: {name}")
        return self.env_cfgs[name](), self.train_cfgs[name]()

    def make_env(self, name, args=None, env_cfg=None):
        if env_cfg is None:
            env_cfg, train_cfg = self.get_cfgs(name)
        else:
            _, train_cfg = self.get_cfgs(name)

        if args is not None and args.num_envs is not None:
            env_cfg.env.num_envs = args.num_envs

        env = self.task_classes[name](
            cfg=env_cfg,
            sim_device=args.sim_device if args else "cuda:0",
            headless=args.headless if args else False,
            play=getattr(args, "play", False) if args else False,
        )

        runner_name = train_cfg.runner.runner_class_name
        if runner_name == "HIMOnPolicyRunner":
            env = HIMRslRlWrapper(
                env,
                history_length=env_cfg.env.history_length,
                one_step_obs_dim=env_cfg.env.num_one_step_observations,
                expected_privileged_obs_dim=env_cfg.env.num_privileged_obs,
            )
        else:
            env = RslRlVecEnvWrapper(env)

        return env, env_cfg

    def make_alg_runner(self, env, name, train_cfg=None, log_root="logs"):
        if train_cfg is None:
            _, train_cfg = self.get_cfgs(name)

        log_dir = None
        if log_root is not None:
            log_dir = os.path.join(
                log_root,
                train_cfg.runner.experiment_name,
                train_cfg.runner.run_name or "default",
            )
            os.makedirs(log_dir, exist_ok=True)

        cfg = class_to_dict(train_cfg)
        rsl_runners = load_project_rsl()
        runner_name = cfg["runner"]["runner_class_name"]
        if runner_name == "HIMOnPolicyRunner":
            runner_cls = rsl_runners.HIMOnPolicyRunner
        elif runner_name == "OnPolicyRunner":
            runner_cls = rsl_runners.OnPolicyRunner
        else:
            raise ValueError(f"unsupported runner: {runner_name}")

        return runner_cls(
            env,
            cfg,
            log_dir=log_dir,
            device=env.device,
        ), train_cfg


task_registry = TaskRegistry()
~~~

make_env 才是“自动完成 wrapper 包装”的位置。若当前实现只返回原始环境，就不能在文档中宣称 wrapper 已自动接通。

## 9. RSL-RL 后端边界

### 9.1 普通 PPO

普通 PPO 的最小交互接口是：

~~~python
obs, privileged_obs = env.reset()

for _ in range(num_steps):
    actions = policy.act(obs)
    obs, privileged_obs, rewards, dones, infos = env.step(actions)
    storage.add(
        observations=obs,
        critic_observations=privileged_obs,
        actions=actions,
        rewards=rewards,
        dones=dones,
        infos=infos,
    )
~~~

RolloutStorage 保存 [T, N, ...] 的 rollout；当前 PPO/HIMPPO 在写入 storage 前消费 time_outs 做 timeout reward bootstrap，随后 compute_returns 主要使用 dones。具体字段名称和调用顺序应以当前 rsl_rl 版本为准。

### 9.2 HIM

HIM 的数据链为：

~~~text
单步 observation [N, D]
        │
        ▼
history buffer [N, H, D]
        │ flatten
        ▼
actor observation [N, H*D]
        │
        ├── HIMEstimator -> latent
        └── HIMActorCritic -> action/value
        │
        ▼
HIMRolloutStorage -> HIMPPO -> HIMOnPolicyRunner
~~~

HIM 专用模块的职责保持单向：

| 模块 | 职责 | 不负责 |
|---|---|---|
| HIMEstimator | 从 history 估计 latent 或隐变量 | 物理步进、任务 reset |
| HIMActorCritic | actor、critic、estimator 的前向组合 | 修改环境状态 |
| HIMRolloutStorage | 保存 history、privileged、terminal frame 等 rollout 数据 | 计算 MuJoCo reward |
| HIMPPO | policy/value/estimator loss 和优化 | 注册任务 |
| HIMOnPolicyRunner | 组织采样、更新、日志和 checkpoint | 解析 MJCF |

### 9.3 AMP 边界

AMP 不应复用 HIMRslRlWrapper 的命名和内部状态。AMP 通常还需要：

- motion clip loader；
- reference state 或 motion observation；
- discriminator observation；
- discriminator replay buffer；
- AMP loss 或 reward；
- AMP 专用 runner/checkpoint 逻辑。

这些组件应位于独立的 AMP adapter 或 rsl_rl 扩展包中。基础环境只提供可复用的机器人 observation、transition 和 episode 信息。若 AMP 与 HIM 同时启用，应明确谁负责 history、谁负责 motion observation，并为两者定义独立的 shape 合同。

## 10. 数学与终止状态约定

### 10.1 四元数逆旋转

以 batch 为例，重力向量在机体坐标系下的投影通常写作：

~~~text
g_body = quat_rotate_inverse(q_world_body, g_world)
~~~

实现时必须确认：

- q_world_body 的旋转方向；
- g_world 和 g_body 分别属于哪个坐标系；
- 四元数排列是 wxyz 还是 xyzw；
- 输入 shape 是 [N, 4] 和 [N, 3]；
- `quat_rotate_inverse()` 对原始向量保留输入单位；但 `projected_gravity` 这个观测 term 必须显式归一化为无量纲方向向量，才能与 `cos(limit_angle)` 终止阈值比较。原始 IMU 加速度仍保持 `m/s^2`，不能混用这两个合同。

math.py 可以提供 torch.jit.script 的批量函数，但 JIT 通过不代表坐标系方向正确；必须用单位四元数、90 度旋转和反向旋转的数值例子验证。
当前仓库尚未完成这些数值断言，且现有函数不自动归一化输入四元数；因此四元数排列、主动/被动旋转方向和数值稳定性均属于未执行/未验证，不得把下面的表达式当作已经证明的部署合同。

### 10.2 GAE 与 timeout

概念上的 TD 误差可以写成：

~~~text
delta_t = r_t + gamma * (1 - terminated_t) * V_{t+1} - V_t
~~~

但当前内嵌 rsl_rl 的实际处理不是让 RolloutStorage 直接读取 time_outs，而是在 PPO/HIMPPO 收到 transition 时先用 transition 中已经保存的 V_t 做 timeout reward bootstrap：

~~~text
effective_timeout_t = truncated_t AND NOT terminated_t
r_bootstrap_t       = r_t + gamma * V_t * effective_timeout_t
storage.compute_returns() 使用 dones
~~~

所以 wrapper 必须把 effective_timeout 写入 infos["time_outs"]，runner/algorithm 必须在写入 storage 前消费它。若把 terminated=True、truncated=True 同时标成 timeout，就会错误地对真正终止状态 bootstrap。

关键字段是：

- terminated：任务真正终止；
- truncated：时间上限或外部截断；
- effective_timeout：允许 timeout bootstrap 的截断；
- dones：terminated 或 truncated，作为 episode mask；
- time_outs：交给当前算法实现的 timeout 辅助字段。

这里的公式和当前代码路径必须一并验证；只看变量名不能证明 GAE 语义正确。

本项目当前内嵌 HIMPPO 的 timeout 处理是 V_t 近似，不是严格的 terminal V_{t+1} GAE：算法在 process_env_step 阶段使用 transition.values 做 timeout reward bootstrap，next_critic_obs 主要服务 HIM estimator。若未来要改成严格的 V_{t+1}，必须同时修改 wrapper 的终止后 observation 合同、runner transition、HIMPPO 和 storage，不能只改公式或字段名。

### 10.3 HIM privileged 与 history 合同

Go2 HIM 的目标维度是 D=45、H=6、actor observation=270、P=235。当前 HIMEstimator 还会按固定切片读取 privileged observation，至少涉及 [3:48] 和 [45:48] 的字段布局。因此 P=235 不是只要数字相等即可，观测拼接顺序也必须写入任务合同。

~~~python
import torch


@torch.jit.script
def wrap_to_pi(angle: torch.Tensor) -> torch.Tensor:
    return (angle + torch.pi) % (2.0 * torch.pi) - torch.pi


@torch.jit.script
def quat_rotate_inverse(q: torch.Tensor, v: torch.Tensor) -> torch.Tensor:
    # 具体四元数排列必须与项目约定一致。
    q_w = q[:, 0]
    q_vec = q[:, 1:4]
    a = v * (2.0 * q_w.square() - 1.0).unsqueeze(-1)
    b = 2.0 * q_w.unsqueeze(-1) * torch.cross(q_vec, v, dim=-1)
    c = 2.0 * q_vec * torch.sum(q_vec * v, dim=-1, keepdim=True)
    return a - b + c
~~~

### 12.3 scripts/export_onnx.py

导出模型前使用一个明确输入输出的 inference module：

~~~python
class PolicyExportWrapper(torch.nn.Module):
    def __init__(self, actor, history_length, obs_dim):
        super().__init__()
        self.actor = actor
        self.register_buffer(
            "history",
            torch.zeros(1, history_length, obs_dim),
        )

    def forward(self, one_step_obs):
        self.history = torch.cat(
            [one_step_obs.unsqueeze(1), self.history[:, :-1]],
            dim=1,
        )
        actor_obs = self.history.flatten(start_dim=1)
        return self.actor(actor_obs)
~~~

导出前应使用与训练相同的 obs_dim、history_length、normalization 和 action mapping。对 HIM 而言，若 actor 需要 estimator latent，导出 wrapper 必须把 estimator 一起包含在图中，或者在部署合同中明确 latent 的来源。

### 14.3 观测维度不一致

### 14.5 terminal privileged observation 被 reset 覆盖

如果 HIM estimator 的 termination frame 变成新 episode 的初始状态，说明底层环境在 reset 后才读取状态。修复方向是：

1. 在底层 reset 前复制 terminal observation；
2. 将它写入 infos["termination_privileged_obs"]；
3. wrapper 只负责抽取和传递；
4. 对没有 terminal frame 的任务显式记录 fallback。

## 15. 推荐落地顺序

### 15.1 仿真-only 与真实硬件安全边界

在动作进入任何执行器之前，至少要有一层唯一且可审计的安全门。仿真 wrapper 可以提前做有限值检查，但不能冒充真实硬件安全控制器。

~~~python
import torch


def validate_sim_action(action, lower, upper):
    if not torch.isfinite(action).all():
        raise FloatingPointError("policy action contains NaN or Inf")
    return torch.clamp(action, lower, upper)
~~~

真实硬件部署还必须独立定义并验证：

- 每个关节的位置、速度、力矩/电流、温度和动作变化率上限；
- 限幅生效的唯一层，以及限幅触发后的故障码和锁存策略；
- 急停输入、触发时限、故障锁存和安全输出；
- 控制 watchdog 的周期、超时阈值和安全动作；
- IMU、关节编码器和通信包的 freshness/validity 检查；
- NaN/Inf、传感器断连、策略线程卡死和通信断连的安全态；
- 分阶段上电、人员隔离、回退到零力矩或阻尼态的操作流程。

当前仓库没有 RTOS、硬件执行器或上述安全控制实现，因此这些项目全部是未执行/未验证 blocker。RL 的 episode timeout 不是控制 watchdog，仿真中能走完全程也不能证明可直接上机。

### 第一步：先完成标准 PPO

完成以下最小闭环：

~~~text
Go2 MJCF
  -> Go2 asset
  -> ManagerBasedRlEnv
  -> RslRlVecEnvWrapper
  -> OnPolicyRunner
  -> 2 个环境 zero-action smoke test
~~~

### 第二步：接入 HIM

只增加：

- HIMActorCritic；
- HIMEstimator；
- HIMPPO；
- HIMRolloutStorage；
- HIMOnPolicyRunner；
- HIMRslRlWrapper。

标准 PPO 的 wrapper 和环境不应因为 HIM 增加而改变返回值含义。

### 第三步：接入 AMP

AMP 使用独立的 adapter、runner、storage 和 motion data pipeline。先完成离线的 observation shape、normalization、motion clip 和 discriminator 输入检查，再接入仿真 rollout。

### 第四步：增加复杂度

按“平地 → 少量环境 → GPU → rough terrain → domain randomization → HIM/AMP → sim2real”的顺序增加变量。任何仿真成功都不能自动证明真实硬件安全，真实部署还需要动作/力矩限幅、急停、watchdog、传感器新鲜度和断连安全态检查。

## 17. 最终架构结论

legged_mjlab 的稳定核心应当只有三条主线：

~~~text
任务配置：BaseConfig -> LeggedMjlabCfg -> Go2/HIM task cfg
环境转换：mjlab Manager env -> standard/HIM wrapper
训练后端：wrapper contract -> PPO/HIM/AMP runner
~~~

配置描述参数，环境描述 transition，wrapper 描述协议，rsl_rl 描述算法。只要这四个边界保持清楚，Go2、HIM、AMP 和后续机器人任务就可以独立演进；如果把 history、latent、motion discriminator 或 runner 逻辑重新塞进基础环境，项目会重新回到难以追踪和难以部署的状态。

本文中的目标实现模板尚未替代实际运行验证。接入新代码后，必须按“配置隔离 → 2-env zero-action → wrapper shape → timeout/terminal frame → 短 rollout → GPU 扩展”的顺序逐项确认。
