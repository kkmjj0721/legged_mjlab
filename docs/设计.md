# 设计

# 引擎部分：

- mjlab 使用的为 MuJoCo Warp，而 isaac 系列使用为 PhysX；

- 这两者的本质差异**在于**物理求解器数学机理（凸优化 vs 脉冲迭代）**以及**底层执行栈的轻重量级（Warp JIT 纯算子 vs Omniverse/PhysX 引擎）

- **MuJoCo Warp：**

  - 袭 MuJoCo 经典的逆动力学与凸优化求解器。足端触地时呈现平滑连续的力过渡，极少出现穿模反弹或接触力瞬时发散，在足端滑移（Slip）、冲击阻尼和摩擦锥计算上更贴合真实物理

  - 运行开销极小，并且底层**完全透明**（物理内核为 Warp Python 语法，可直接改）

  - 但**高保真渲染与传感器**弱（主打纯动力学仿真，无原生光追传感器管线）

- **Isaac 系列：**

  - 基于游戏物理引擎演化而来的 TGS/PGS 求解器。其速度极快，但在处理刚性大冲击（如落地碰撞、快速腾空跳跃）时，容易因 `rest_offset` 和 `contact_offset` 调参不当出现足端高频抖动、悬空踩空或微小弹跳
